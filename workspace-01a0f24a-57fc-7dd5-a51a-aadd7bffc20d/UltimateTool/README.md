# OmniKit

Самодостаточный мультитул для Android: **AI-чат с любой OpenAI-совместимой
моделью/эндпоинтом**, **платформа Lua-плагинов**, **виртуализация Linux без
root (proot)**, **33 встроенные утилиты**, вход без пароля, темы (включая
AMOLED) и раздел сообщества. 100% Kotlin, UI — Jetpack Compose (Material
Design 3).

> Приложение переименовано из UltimateTool → **OmniKit** (пакет
> `com.ultimatetool.app` сохранён, данные не теряются).

## Функции

### 🤖 AI-чат: любая модель, любой эндпоинт
* **Свой базовый URL**: OpenAI, OpenRouter, Together, Groq, **Ollama**,
  LM Studio — всё, что говорит по протоколу `/v1/chat/completions`.
* **Любое имя модели**: пресеты + свободный ввод, сохранение модели по
  умолчанию (шифрованное хранилище).
* История в Room, Markdown-рендер (Markwon), выделение текста сообщений,
  автопрокрутка, защита от двойной отправки, очистка и экспорт диалога.

### 🐧 Виртуализация Linux без root и без сторонних приложений
* Подход **proot-userland** (как в UserLAnd/AnLinux): системные вызовы
  перехватываются в userspace, гостевая система живёт в каталоге приложения.
* **Каталог из 8 дистрибутивов**: Alpine 3.20, Ubuntu 24.04, Debian 12,
  Arch, Kali, Fedora, Void, openSUSE (для экспериментальных — свой URL).
* Конвейер: скачивание бинарника `proot` под ваш ABI → скачивание rootfs →
  распаковка собственным тар-экстрактором (поддержка `.tar`, `.tar.gz`,
  `.tar.xz`, симлинков, с защитой от zip-slip) → запуск `/bin/sh` под proot.
* **Терминал** запущенного дистрибутива (линейный ввод/вывод, буфер 40 КБ).
* **Графическое окружение** через VNC: установка/запуск VNC-сервера внутри
  гостя одной командой, встроенный просмотрщик (noVNC-мост), порт 5901.
* Прогресс установки, журнал, остановка и удаление дистрибутивов.
* Честные ограничения: полноценный PTY и пиксельный RFB-клиент — отдельные
  большие задачи; `proot`-бинарник и rootfs скачиваются в рантайме;
  аппаратное ускорение (KVM) без root невозможно.

### 🛠️ 33 встроенные утилиты
* **Крипто**: Base64, Хэши (MD5/SHA-1/SHA-256/SHA-384/SHA-512/CRC32),
  JWT Decoder (+проверка HS256), AES-256-GCM (PBKDF2 из пароля),
  TOTP/2FA (RFC 6238, офлайн).
* **Текст/данные**: JSON, URL Codec, Regex, Diff Viewer (LCS), CSV-таблица,
  Текстовый инспектор, **Текст ↔ hex/бинарный**, **Морзе**.
* **Генераторы**: UUID, Пароли, Timestamp, Конвертер цветов,
  **Случайное** (число/элемент списка).
* **Сеть**: HTTP-тестер, TCP Ping, IP Lookup (ipwho.is), DNS over HTTPS,
  **Порт-сканер** (популярные порты/диапазон, таймаут 350 мс),
  **WHOIS** (IANA), **Калькулятор подсетей (CIDR)**.
* **Конвертеры**: **Основания счисления** (2/8/10/16), **Величины**
  (длина/масса/данные/температура), **ИМТ**, **Точный возраст**.
* **Система**: QR-генератор (ZXing), **Устройство** (расширенная сводка:
  чип, ядро, память, батарея с температурой, датчики, сеть, экран),
  **Хэш файла** (любой файл через SAF, потоково), **Озвучка текста (TTS)**.

### Остальное
* Авторизация без пароля (код через бэкенд / биометрия / демо-режим).
* Платформа Lua-плагинов: песочница, редактор, запуск, пример.
* Сообщество, Профиль (экспорт данных, выход), Настройки.
* Темы: Система/Светлая/Тёмная/**чёрная AMOLED**, Dynamic Color.

## Сборка

✅ Проверено: `./gradlew assembleDebug` + `testDebugUnitTest` — все тесты
зелёные (36: ядро + функциональность + дополнения: TOTP-векторы RFC 6238,
AES round-trip, diff, цвета, tar-распаковка, генераторы, подсети, Морзе,
основания счисления, единицы измерения).

```bash
./gradlew testDebugUnitTest   # юнит-тесты
./gradlew assembleDebug       # debug APK
```

Для машин с ≤2 ГБ RAM память сборки уже настроена в `gradle.properties`
(SerialGC, один воркер, Kotlin in-process).

## Безопасность и закон

* Токены и ключи — в `EncryptedSharedPreferences`; плагины — в песочнице.
* Сетевые утилиты (порты, HTTP) применяйте **только к собственным системам**:
  сканирование чужих узлов незаконно.
* Виртуализация работает без привилегий и ничего не ломает на устройстве:
  гостевые системы — обычные каталоги, удаляются одной кнопкой.
